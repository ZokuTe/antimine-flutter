# 直播联动

观众在 B 站直播间发弹幕，操作游戏里一个**所有人共享的光标**。

协议实现就在进程内（`data/bilibili_danmaku_client.dart`），没有外部进程要管，
所以设置里一个开关就能起停。只在 Windows / Linux 上启用（见 `live_support.dart`）。

## 观众怎么玩

一条弹幕可以是一整串操作，每个操作前面能带**一位数**的次数：

```text
下        下移一格
3下       下移三格
2右3下     右两格再下三格
3下开      下移三格，然后在那一格挖开
```

| 词 | 效果 |
| --- | --- |
| `上` `下` `左` `右` / `w` `a` `s` `d` | 挪共享光标 |
| `开` `挖` | 在光标处挖开 |
| `旗` `插旗` | 插旗 |
| `问` `?` `？` | 问号 |

次数是 **1–9**，`0` 和两位数（如 `10下`）不合法。

**整条必须都能解析出来，认出一个字失败就整条丢弃**——`右x` 什么都不做，而不是
先右一格。同时不做子串匹配：`开播了吗` 不因为含「开」就算指令。观众得能预测
自己那句话会干什么。

词表在 `logic/live_command.dart` 的 `defaultLiveVocabulary`，改指令只动那一处。

### 几个语义

- `3下开` 里的「开」落在**移动之后**的格子上，不是原位。整串按顺序执行，
  每个动作取它前面那些移动之后的光标。
- 一条弹幕只算一条 `accepted`，哪怕它带了 9 个操作。
- 光标**夹在盘面内**，撞边停住不环绕。换局（尺寸变了）会重新夹一次。
- 弹幕指令之间**串行**执行。这不是限流，一条都不丢，只是排队——`GameBloc`
  的 `_updateState` 内部有一次 `await`，并发进去会让某些 emit 带上过期的 `areas`。

## 粉丝牌门槛

设置里 `Fan badge required`，默认**开**：只放行戴着**本直播间**粉丝牌的弹幕。
关掉之后访客（没牌子、或戴别家牌子）也能操作。

判定在 `LiveBloc`，不在协议层——那是主播开播中会随手切的开关。

⚠️ `medal_level > 0` **不等于**「我的粉丝」，它只说明戴了*某个*直播间的牌子，
别家的 30 级牌子也成立。必须比 `medal_room_id == 本房真实房间号`。

⚠️ 比的是 `hello` 报过来的**真实房间号**，不是设置里填的短号。实测短号 `1` 会
解析成 `5440`。

## SESSDATA 可以不填

设置里有这一项，但**不影响功能**。实测匿名连接（不给 SESSDATA）一样能拿到：

- 完整用户名（不是打码的 `栞***`）
- 粉丝牌等级和 `medal_room_id`

所以它只是换个身份用，空着完全能跑。

## 协议要点（改之前先读）

三个坑，都是实测踩出来的：

**1. `getDanmuInfo` 必须带 WBI 签名**，不带就是 `-352`。这不是猜的——blivedm
源码里直接写着 `if data['code'] == -352: # wbi签名错误`。

签名算法：`nav` 接口拿 `wbi_img.img_url` / `sub_url` → 各取文件名去扩展名拼成
64 字符 → 按一张 32 项的固定索引表（`_wbiKeyIndexTable`，照抄 B 站前端）抽出
密钥 → 请求时补 `wts`、按键字典序排序、去掉 `!'()*`、urlencode 后拼密钥取 md5
当 `w_rid`。密钥缓存 12 小时（B 站会轮换）。

注意 `nav` 匿名会回 `code: -101`，但 `data.wbi_img` 照样有，所以那次请求不能走
「code 必须为 0」的检查。

**2. 认证包显式要 `protover: 2`（zlib）。** 这是原生实现能成立的前提：zlib 解压
`dart:io` 自带，而默认的 `protover: 3` 是 brotli，Dart 没有内置实现，就得引第三方包。

`protover 2` 的包体是 zlib 压缩的**一批包**，解完还要递归当包解。

**3. 短号 → 真实房间号要先解析。** `room/v1/Room/get_info` 的返回里 `room_id` 才是
真实号，粉丝牌的 `medal_room_id` 用的也是它。

## 验证

改过协议逻辑先跑这个，纯 Dart、不启动界面：

```sh
dart run tool/live_probe.dart <房间号> [秒数]
```

```text
hello: 真实房间号 = 26966466
弹幕 35 条，其中带牌子 34 条，心跳 1 次
  鸢一千代纸 | 喝水 | 牌子 36 级 / 房间 26966466
```

「心跳 N 次」是关键：心跳回执（op=3）要等 30 秒才来一次，收到它就说明**整条解码
链路（含 zlib 解包）是通的**，不只是能连上。所以抓取时间建议 ≥ 40 秒。

单元测试：

```sh
flutter test test/features/live/
```

`data/bilibili_danmaku_client.dart` 只依赖 `dart:*` 和 `crypto`，不碰 Flutter，
所以能脱离界面单独跑和测。
